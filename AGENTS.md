# Agent notes

## Cursor Cloud specific instructions

Do not record walkthrough videos, capture demo screenshots, or attach screenshot/video galleries in pull requests or chat replies unless Hashim explicitly asks for them.

They are not useful for review in this repo and they burn agent usage/credits.

Proof of work should be:

- the smallest relevant automated tests (`pytest`, etc.)
- a short written note of what was checked
- git / PR status when that is the actual question

You may still click through the UI internally when a layout or interaction change needs it. Do not save those captures, do not upload them, and do not embed them in the summary or PR body.
